
# Calcolatore Netto da RAL (Prototipo Jet HR)

Prototipo ultra-semplice: dato una **RAL**, stima:
- Netto annuo
- Netto mensile
- Tasse totali
- Contributi INPS

## Assunzioni
- Dipendente tempo indeterminato, residenza fiscale a Milano
- Nessuna agevolazione/detrazione extra
- Aliquote semplificate:
  - INPS: 9,19%
  - IRPEF: 30%
  - Addizionali: 2%
